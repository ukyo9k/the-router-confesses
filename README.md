An entry for the [make.fun bounty "The Router Confesses"](https://make.fun/bounty/u-carbon-forge-the-router-confesses-f98f6b9e): one line in which a home Wi-Fi router excuses itself for dropping the connection at the exact climax of a movie.

The router in question has a grudge, a fragile ego, and one smug little secret — it already knows how the movie ends, and it has decided you don't get to find out either.

## The line

> I know who did it — and after you named me 'FBI Surveillance Van' and never once thanked me, I've decided you never will.

## How to run

Python 3, standard library only — no dependencies, no network access.

```sh
python3 main.py
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output/entry.txt`). The output is deterministic: running it twice produces byte-identical files.
